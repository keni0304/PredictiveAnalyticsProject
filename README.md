# Predictive Analytics Using Historical Data

## Objective
Build a predictive model to forecast future sales trends using Linear Regression.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Dataset
Historical monthly sales data (2023–2025).

## Features
- Data preprocessing
- Linear Regression model
- Sales forecasting
- Model evaluation (MAE, MSE, R²)
- Data visualization

## Output
Forecasts future sales for the next six months.
